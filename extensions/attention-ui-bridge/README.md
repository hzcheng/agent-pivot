# Agent Pivot Attention UI Bridge

This UI-host companion lets Agent Pivot windows on the same machine exchange bounded AI-session attention state through profile-local files. It contains no user-facing commands and records no conversation content, prompts, responses, hostnames, remote authorities, or absolute project paths.

Install this extension locally before installing Agent Pivot in local, SSH, WSL, or Dev Container extension hosts.

Agent Pivot began as a fork of Kruemelkatze/vscode-dashboard and retains the upstream MIT attribution.
