# Agent Pivot Brand Identity Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the unpublished Project Steward identity with the original Agent Pivot identity across artwork, manifests, runtime namespaces, documentation, licensing, packaging, and release verification without changing product behavior.

**Architecture:** Treat the two extension manifests as the public identity authority and expose their invariant values through one small build-time contract module. Generate raster Marketplace icons from reviewed SVG masters, migrate every current runtime namespace atomically, and make stale identity, inherited icon bytes, incomplete notices, or malformed VSIX contents fail deterministic release checks. Keep historical design records and required fork attribution through a narrow, reviewed scanner allowlist.

**Tech Stack:** VS Code Extension API, TypeScript 4, Node.js CommonJS and `node:test`, Webpack/Gulp, Sharp 0.35.3, SVG/PNG, VSIX/ZIP inspection, GitHub Actions.

## Global Constraints

- The public product name is exactly `Agent Pivot`.
- The main manifest identity is exactly `hzcheng.agent-pivot`, with package name `agent-pivot`, publisher `hzcheng`, and first Agent Pivot version `1.0.0`.
- The companion manifest identity is exactly `hzcheng.agent-pivot-attention-ui-bridge`, with package name `agent-pivot-attention-ui-bridge` and publisher `hzcheng`.
- Public commands and settings use `agentPivot.*`; the Activity Bar container is `agentPivot`; the dashboard view is `agentPivot.dashboard`.
- The intended repository URL is `https://github.com/hzcheng/agent-pivot.git`; changing the remote repository itself is separately authorized release work.
- Do not add compatibility aliases or migrate Project Steward settings, global/workspace state, Bridge state, or managed tmux sessions. The unpublished identity starts clean and may coexist with a separately installed old extension.
- Preserve Codex, Claude, Kimi, session, conversation, project, prompt, todo, refresh, and webview behavior.
- Use Pure Axis artwork: Marketplace background `#111924`, rail `#69DFD0`, ring highlight `#D8FFF9`, flat color, no gradient, and no Sharingan artwork in the primary logo or Marketplace hero.
- Keep Sharingan assets only as optional in-product animation and retain their attribution.
- Do not create repository social-preview or publisher artwork in this local plan; any later external preview must use Pure Axis and must not use Sharingan artwork.
- Preserve the upstream MIT copyright notice and add `Copyright (c) 2026 hzcheng`.
- Include notices for every JavaScript library copied into the shipped webview and ship the selected Apache-2.0 license text for DOMPurify.
- Historical changelog entries, fork attribution, license notices, and approved design evidence may mention Project Steward or upstream names; current production code, manifests, workflows, release copy, and current user documentation may not.
- Never publish, rename the GitHub repository, remove another installed extension, or mutate Marketplace state as part of this plan.
- Use `apply_patch` for authored changes. Use the repository build tasks for generated bundles and Webview mirrors.
